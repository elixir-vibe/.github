# Elixir Vibe Organization Profile

This repository contains the public GitHub organization profile for Elixir Vibe.

## Scope

Keep `profile/README.md` concise and ecosystem-focused. It should explain what the organization contains, how the projects fit together, and link to the main repositories.

## Guidelines

- Do not duplicate full project documentation here.
- Keep package descriptions aligned with each repository's `mix.exs` description.
- Use stable GitHub and Hex package links.
- Update the package table when repositories are added, renamed, archived, or transferred.
